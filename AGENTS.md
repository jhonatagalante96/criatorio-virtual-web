# Codex instructions — Criatório Virtual Web

## Scope

Implement only the requested backlog card. Do not add future screens, integrations, dependencies, or design-system abstractions that the card does not require.

## Product principles

- Build mobile-first, responsive interfaces.
- Keep domain and API contracts explicit.
- Never expose one tenant's data to another tenant.
- Provide loading, empty, validation-error, and failure states where relevant.
- Keep accessibility and clear Portuguese (Brazil) user-facing text in scope.

## Quality

Add or update automated tests where the chosen frontend stack supports them. Validate authorization/session behaviour and API error handling for every affected user journey.

## Workflow

Read `README.md` and `CONTRIBUTING.md` before changing code. Work from `develop` in a focused branch. Use English Conventional Commits and keep pull requests limited to one backlog card or subtask.
